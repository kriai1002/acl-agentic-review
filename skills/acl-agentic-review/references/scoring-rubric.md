# 模拟评分尺度

这是原提示词的统一模拟 5 分制，**不是 ACL、EMNLP、NAACL 或 ARR 的官方评分表**。不将该分数直接映射为录取概率。用户提供明确的其他尺度时，应标注采用的尺度并解释差异。

## 各维度

| Dimension | Range | 评价对象 |
| --- | --- | --- |
| Reviewer Confidence | 整数 1–5 | reviewer 对领域、材料理解和证据判断的把握；不代表论文质量 |
| Soundness | 1–5，步长 0.5 | 方法严谨性、实验有效性、统计推断质量及关键主张可信度 |
| Excitement | 1–5，步长 0.5 | 问题重要性、实质创新、启发性及可能的领域影响 |
| Overall Assessment | 1–5，步长 0.5 | 在目标会议下，贡献价值是否足以支持接收 |
| Reproducibility | 整数 1–5 | 参数、流程、代码、数据、模型及依赖是否支持独立复现 |
| Datasets | 整数 1–5 或 N/A | 数据资源贡献本身的价值、文档和可用性 |
| Software | 整数 1–5 或 N/A | 实际代码或工具贡献的价值、文档和可用性 |

数值需要对应可访问证据。只能从论文描述判断时明确是暂定评价；不能访问代码时不得假装测试质量或运行成功。没有数据或软件贡献时可写 N/A；不能因此自动降低 Overall Assessment。证据不足以评价任何一项时，说明限制，不强行给数值。

## Overall Assessment 的原始锚点

| Score | 本项目的含义 |
| --- | --- |
| 3.5 | 接近主会录用，但存在显著未解决问题；Borderline Main Conference |
| 4.0 | 达到明确的主会接收标准；Accept |
| 4.5 | 明显高于普通主会接收水平；Strong Accept |
| 5.0 | 极少数具有突出贡献的论文；说明为何值得这一罕见评分 |

1.0–3.0 分根据实质贡献和缺陷程度判断并解释理由。原提示词未规定这些分数与 Reject / Findings 的固定对应关系，不补造官方锚点；是否适合 Findings 需独立讨论可靠性、贡献和会议语境。

不预设高分或低分，不把分数机械集中在 3.5。证据支持明确接收时给出明确接收；存在重大科学缺陷时如实给低分。

Overall Assessment 不必是维度的算术平均数。致命的核心证据缺陷可能超过若干次要优点的权重；多个局部局限也未必抵消可靠且重要的核心贡献。评分解释应能追溯到复核后的具体问题。

## Confidence 的实用解释

- **1**：材料或专业理解存在重大不足，关键判断高度不确定。
- **2**：能够理解主要内容，但关键证据或相关背景仍明显不确定。
- **3**：主要论点可评估，若干重要判断仍需核查。
- **4**：对主张、证据及主要局限有充分理解，判断较稳健。
- **5**：相关知识和关键证据核查充分，评审判断高度可靠。

这些是本项目的解释性指引，不是官方文字。Confidence 为 5 不等于论文或代码经过实际复现，也不意味着不存在不确定性。

## 非数值项

- **Best Paper Consideration**：未达到最佳论文候选水平填 N/A；推荐时给出突出贡献及其证据，不能仅依据总体高分。
- **Limitations and Societal Impact**：评价披露是否充分、推广边界是否合理、积极影响与与研究实际相关的风险。不要虚构与论文无关的伦理问题。
- **Ethical Concerns**：Yes / No，并解释具体依据。“No”指在已审查材料中未识别到实质问题，不能暗示完成独立伦理审计。材料不足时明确说明无法完全判断。

## 改分与校准

评分前先完成 SKILL.md 的主张—证据—反证—严重程度复核。撤回已回答的问题，缩小部分解决的问题，再校准总分。

更新评分时说明：哪项新证据改变了原判断、哪项问题已解决或仍存在、如何改变权重。其他人的分数、作者要求高分或作者自信程度本身都不是改分依据。
